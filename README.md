Aplicativo mobile desenvolvido para facilitar o agendamento de serviços em salões de beleza. A interface foi construída pensando na experiência do usuário (UX), permitindo uma navegação fluida e intuitiva.

> **Nota:** Este projeto consome a API RESTful desenvolvida em Spring Boot, disponível [neste repositório](https://github.com/EXTProgrammer/salao_app_api).

## 🚀 Tecnologias Utilizadas
* **React Native**
* **Expo** (facilitação do ambiente e testes)
* **React Navigation** (Navegação por abas/Tab Navigation)

## ⚙️ Funcionalidades da Interface
* **Interface de Agendamento (Scheduling UI):** Telas amigáveis para seleção de datas e horários disponíveis.
* **Navegação por Abas (Tab Navigation):** Estrutura de navegação para facilitar o acesso entre o perfil do cliente, agendamentos e visualização de avaliações.
* **Consumo de API:** Integração assíncrona com o backend para refletir dados em tempo real.

## 🛠️ Como rodar o projeto localmente

### Pré-requisitos
* Node.js instalado
* Conta e aplicativo do **Expo Go** instalados no seu smartphone (ou um emulador configurado no PC).

### Passos
1. Clone este repositório:
   ```bash
   git clone [https://github.com/EXTProgrammer/salao-app-mobile.git](https://github.com/EXTProgrammer/salao-app-mobile.git)

2. Instale as dependências do projeto:
   npm install
   ou
   yarn install

3. Inicie o servidor do Expo:
   npx expo start

4. Escaneie o QR Code gerado no terminal usando o aplicativo Expo Go no seu celular.
